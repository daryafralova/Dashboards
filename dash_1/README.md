#  Операционная эффективность и удовлетворённость клиентов на маркетплейсе Olist.

## Бизнес-задача
Руководство Olist замечает корреляцию между ростом количества заказов и увеличением жалоб на доставку. 
Необходимо создать дашборд в DataLens, который ответит на вопросы: 
- Насколько быстро мы доставляем заказы?
- Влияют ли опоздания на оценки?
- Где находятся самые проблемные точки (регионы/категории)?

## Цель проекта
Создать интерактивный дашборд для мониторинга ключевых метрик маркетплейса:
- Влияние просрочек доставки на оценку клиента
- Топ проблемных категорий и регионов
- Динамика продаж и среднего чека

## Ключевые метрики:
**Главные KPI:**
- `Total Revenue` — общая выручка (товары + доставка)
- `Average Order Value (AOV)` — средний чек
- `Average Review Score` — средняя оценка клиентов (1-5)
- `Late Delivery Rate` — процент просроченных доставок

**Логистика:**
- `Average Delivery Days` — среднее время доставки (дней)
- `SLA Breach Rate` — доля заказов с нарушением срока

**Качество:**
- `Review Drop` — падение оценки из-за просрочки (ключевой инсайт!)
- `Critical Reviews Rate` — доля негативных отзывов (1-2 звезды)

**Аналитика продаж:**
- `Top 5 Categories by Revenue` — топ прибыльных категорий
- `Late Rate by Customer State` — карта просрочек по штатам
